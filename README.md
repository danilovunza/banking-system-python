# Banking System

## Overview

The Banking System is a Python application built using Object-Oriented Programming principles.

The system allows users to create accounts, deposit funds, withdraw money, transfer funds, and review transaction history.

---

## Features

* Create Accounts
* Deposit Funds
* Withdraw Funds
* Transfer Funds
* View Account Information
* Transaction History

---

## Classes

### Customer

Stores customer information.

### Account

Stores account information and balance.

### Transaction

Stores transaction records.

### Bank

Manages all banking operations.

---

## Technologies Used

* Python 3

---

## Skills Demonstrated

* Object-Oriented Programming
* Encapsulation
* Multiple Classes
* Object Relationships
* Banking Logic
* Transaction Tracking
